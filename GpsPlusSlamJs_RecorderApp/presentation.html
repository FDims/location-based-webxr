Motivation & Use Cases

The Core Problem

Existing reference points require physically walking the phone to the landmark. We needed a way to mark points in 3D space that cannot be physically touched (e.g., across the street).

Short Range

(Depth-Dominated)

  • Target is a few meters away.
  • Depth map is reliable.
  • Single well-aimed ray + depth pins the point down.

Long Range

(Parallax-Dominated)

  • Target is 100-200m away.
  • Depth is useless.
  • Walk sideways to build a wide baseline, triangulating via multiple rays.

The Evolution (Before vs After)

Before

  • No integrated remote measurement workflow.
  • Users lacked feedback on measurement accuracy (uncertainty).
  • Invisible rays during capture & coordinate conversions were buggy (NUE scrambled).
  • Replay mode lacked safeguards (double counting rays) and fluid UX.
  • Ghost dots appeared at [0,0,0] origin when GPS not aligned.

After NEW

  • Active Baseline Coaching (prompting to "move sideways").
  • Visual uncertainty feedback via Yellow Provisional Spheres.
  • Solid Green (AR) and Orange (GPS) dots mark the point.
  • Robust MSAC solver triangulation logic with depth priors.
  • Enhanced Replay: Scrubbing, paused start, UI speed feedback, and safe deterministic replays enabled.
  • Fixed invisible rays, FPS mode enabled, UI overlap bugs resolved.

Technical Architecture Deep Dive

1. Pure Estimator Math

Closest Point of Approach solver with RANSAC robust outlier rejection. Treats depth as a soft, distance-weighted prior that triangulation out-votes over distance.

2. Redux State & Persistence

Measurement Point entity persists via the library store. Ensures the marking flow replays deterministically without needing custom stores.

3. Aiming & AR Capture

Crosshair uses device-forward axis; tap-to-aim unprojects the pixel via camera intrinsics. Ray capture happens seamlessly in AR.

4. Dual-Frame Visualization

Solved in AR-local frame, stored in both AR and GPS coordinates. Rendered as two connected dots serving as a live alignment-error probe.

User Workflow

1

Aim & Shoot

Align crosshair or tap target to capture the first observation ray.

2

Build Parallax

Follow coaching prompts to "move sideways". Shoot additional rays to widen the baseline.

3

Observe & Refine

Watch the provisional yellow sphere solidify as uncertainty shrinks with more rays.

4

Confirm & Save

Tap confirm. Point is saved as persistent Green (AR) and Orange (GPS) dots.
