Limitation of recorder app

  • Existing reference points: Physically walking with phone to + around landmark
  • Problem: What if we cannot physically touch the landmark? E.g. top of SuperC
  • Solution:
    • Mark landmarks location in 3D space via ray-triangulation
    • Combine with camera’s depth sensor, reject outliers
      → Measurement sphere(s)
    • Result persisted and visualized in 3D world
    • Asterisk: depth reading less useful for farther (100m+) targets
      → Repeatedly move sideways and mark landmark to refine triangulation
  • Additionally: Replay functionality extended to handle new measurements

(Implementation) Details

  • Crosshair and tap-screen-location ray shooting modes
  • Undo last ray button
  • Active coaching hints to gain baseline -> parallax
  • Uncertainty/error current measure + measureent confirm threshold
  • Random Sample Consensus (RANSAC) outlier rejection
  • Measurement point: AR-local position (green sphere) connected to GPS-world position (orange sphere) via live alignment probe white line)
  • Integration with base recorder app UI without text/box overlay etc.
